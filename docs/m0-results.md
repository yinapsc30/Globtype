# M0 兼容性验证结果

## 联调顺序

1. 安装：`cp -R build/Globtype.app /Applications/` 后打开 `/Applications/Globtype.app`（本机构建没有隔离标记，不需要放行）
2. 引导：授予辅助功能 → 输入监控，确认引导自动进入下一步、菜单栏图标不再显示警告
3. 签名矩阵：改一行代码后 `Scripts/bundle.sh` 重新打包并覆盖安装，确认两项权限仍有效（见下方签名矩阵）
4. 诊断模式：菜单栏 → 诊断…，勾选诊断模式，按下方 App 矩阵逐个测试，然后复制表格贴到这里
5. 输入法矩阵：分别在三种输入法下测试双击 Shift
6. 翻译主流程：设置 → 翻译服务商填入 Key，测试连接；关闭诊断模式后试翻译、润色（输入英文）、R 换个说法、Tab 讲解、Enter 替换、⌘Z 撤销、⌥Enter 不记录、Esc 关闭
7. 学习层：替换几次后打开表达库检索、在译文中选中文字加入复习；菜单栏 → 今日复习走一遍闪卡
8. 兜底：清空服务商（选 Apple 翻译）再翻译一次；在密码框里双击 Shift 确认没有反应

出问题时请记下 App、输入法、有无选区，并附上诊断表格或这条命令的输出：

```bash
log show --last 5m --predicate 'subsystem == "app.globtype"' --style compact
```
